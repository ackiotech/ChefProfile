# SR Chef Portfolio

Personal chef portfolio for Sathyanarayanan Ramkumar ([@sathyacannotcook](https://www.instagram.com/sathyacannotcook)) — community chef at Ängsbacka, Sweden.

## View it live

Once this repo is pushed to GitHub, turn on **GitHub Pages**:

1. Go to the repo's **Settings → Pages**
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`
3. Set **Branch** to `main` and folder to `/ (root)`
4. Save — the site will publish at `https://<your-username>.github.io/sr-chef-portfolio/`

## Structure

```
index.html      the whole site (single page, sections linked from the nav)
assets/logo.png the SR logo, used in the header, hero and footer
assets/logo.svg vector source of the logo, used as the favicon
```

## Editing

The page is plain HTML with inline styles — open `index.html` in any editor. Sections marked `[ADD: ...]` in a dashed box are placeholders for photos, numbers and testimonials still to fill in.
